# CampusBrain design system

The reference palette is preserved: charcoal `#232522`, cream `#FBF9DE` / `#E4E3BE`, sage `#C9CAA9`, orange `#EA6A2F`, blue `#A9B8EA`, and green `#A8DDB0`. Components use large rounded panels, editorial spacing, monospace eyebrow labels, and responsive bottom navigation on narrow screens.

The canonical file is `REF/campusbrain3.html` and must remain unchanged. New UI should reuse the tokens in `frontend/src/styles/tokens.css`, provide visible keyboard focus, and respect reduced-motion preferences.
